# Consumer Spending Trends & Economic Insights

This is a starter Quarto report using Python and a synthetic sample CSV.

## Files
- `consumer_spending.qmd` — Quarto source document
- `consumer_spending_raw_dataset.csv` — synthetic practice data

## Render
Install Quarto and a Python environment with `pandas` and `matplotlib`, then run:

```bash
quarto render consumer_spending.qmd
```

The output is an HTML report. The dataset is synthetic and must be replaced with verified public data before drawing real-world economic conclusions.
